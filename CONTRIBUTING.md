# Contributing Guide

## Branch Naming
- `feature/xyz` — new feature
- `fix/xyz` — bug fix
- `docs/xyz` — documentation
- `refactor/xyz` — code cleanup

## Commit Message Format
- `feat(backend): add JWT auth`
- `fix(frontend): heatmap crash on mobile`
- `docs(readme): update setup`

## Workflow
1. Pull latest main: `git checkout main && git pull`
2. Create branch: `git checkout -b feature/your-feature`
3. Commit small changes
4. Push: `git push origin feature/your-feature`
5. Open Pull Request on GitHub
6. Request review from 1 teammate
